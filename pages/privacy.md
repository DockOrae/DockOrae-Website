This page explains how the DockOrae project and documentation site handle your information.

## The Panel (Self-hosted)

DockOrae is **self-hosted software** running on your own server:

- **Your data belongs to you** — panel data (SQLite database, settings, users, app store data) is stored in your server's data directory and never passes through any third party
- **No telemetry** — the panel does not collect or upload any usage statistics or telemetry data
- **License verification** — when Pro features are enabled, the panel communicates with a License Server to verify license status (sending device identifiers and timestamps to prevent abuse; the License Server stores only SHA-256 hashes of activation tokens, never plaintext)

## Documentation Site (GitHub Pages)

This documentation site is hosted on GitHub Pages:

- Served by [GitHub](https://docs.github.com/en/pages), subject to the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement)
- No third-party analytics tools or tracking cookies are used
- The site search is a local full-text search — search terms are processed only in your browser and never uploaded

## External Links

The documentation contains links to external sites such as GitHub and Docker Hub. Their privacy policies are independent of this one; please review them separately.

## Contact

For privacy-related questions, please contact us via [GitHub Issues](https://github.com/DockOrae/DockOrae/issues).

本页说明 DockOrae 项目与文档站如何处理你的信息。

## 面板(自托管)

DockOrae 面板是**自托管软件**,运行在你自己的服务器上:

- **数据完全归你所有** — 面板数据(SQLite 数据库、设置、用户、应用商店数据)存储在你服务器的数据目录中,不经过任何第三方
- **无遥测** — 面板不收集、不上传任何使用统计或遥测数据
- **许可证验证** — 启用 Pro 功能时,面板会与 License Server 通信以验证许可证状态(发送设备标识与时间戳,用于防滥用;License Server 仅保存激活令牌的 SHA-256 哈希,不保存明文)

## 文档站(GitHub Pages)

本文档站托管于 GitHub Pages:

- 由 [GitHub](https://docs.github.com/en/pages) 提供服务,受 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement)约束
- 本站不使用第三方分析工具,不设置跟踪 Cookie
- 本站搜索为本地全文搜索,搜索词仅在你的浏览器内处理,不会上传

## 外部链接

文档中包含指向 GitHub、Docker Hub 等外部网站的链接。这些网站的隐私政策与本政策相互独立,请自行查阅。

## 联系我们

如有隐私相关问题,请通过 [GitHub Issues](https://github.com/DockOrae/DockOrae/issues) 联系我们。
